202 ok
it is a HTTP status code which means that - The Request was Successfull and the server processed it correctly 
 

401 unauthorized 
the client must authenticate itself to get the requested response. For example - user tries to access API without loggin in 

403 Forbidden 
the client is authenticated but is not allowed to use the resources.m For example - A normal user tries to access an admin-only API.


405 Method Not Allowed 
the HTTP method used  is not supported for the requested resources  

500 internal server errorThe Server is temporarily unavailable usually due to maintenance or overload
