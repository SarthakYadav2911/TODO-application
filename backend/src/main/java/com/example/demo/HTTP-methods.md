What is Get?
GET is an HTTP method used to retrieve (fetch) data from a server.
For Example,
"Hey server, give me some data."
It does not create, update, or delete anything.

What is POST?
POST is an HTTP method used to send data to the server and create a new resource.
for example 
"Hey server, save this new data."

What is PUT?
PUT is an HTTP method used to update an existing resource completely.
for example
"Hey server, replace the old data with this new data."

What is Delete?
DELETE is an HTTP method used to remove a resource from the server.
for Example 
"Hey server, delete this data."
